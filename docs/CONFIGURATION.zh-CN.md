# 参数与排障

[English](CONFIGURATION.md) · **简体中文**

## 环境文件

以 `.env.example` 为准。`LANVORYN_SOURCE=linux` 使用真实设备，`demo` 明确产生测试画面和 440 Hz 测试音。不会自动降级。`LANVORYN_MEDIA_HOST` 决定媒体候选地址；`LANVORYN_PUBLIC_ORIGIN` 决定反向代理后的合法网页来源。`LANVORYN_ALLOWED_CIDRS` 可填写逗号分隔的 IPv4/IPv6 网段，设置后必须包含实际访问来源和运维所需的回环地址。

运行时凭据与配置保存在 `LANVORYN_DATA_DIR` 下；systemd 安装默认使用 `/var/lib/lanvoryn`。`credentials.json` 保存密码哈希，`sessions.json` 保存登录会话与令牌哈希，`config.json` 是带 revision 的设置，`events.json` 最多 200 条。导出的配置不包含账号或密码。

使用 systemd 部署时，服务实际读取 `/etc/lanvoryn/lanvoryn.env`。源码目录 `.env` 仅在首次安装时复制，重新安装会保留已部署的环境文件。修改后执行 `sudo systemctl restart lanvoryn`。若修改 `LANVORYN_MEDIA_HOST`，还需重新生成并安装媒体配置，仅重启应用不够。

## 登录会话

`LANVORYN_SESSION_IDLE_HOURS=168` 表示连续 7 天未使用后过期，`LANVORYN_SESSION_MAX_HOURS=720` 表示从登录起最长有效 30 天，续期不会延长这一上限。两项均可配置，最大值为 720 小时。原固定有效期设置 `LANVORYN_SESSION_HOURS` 不再读取。

打开或返回可见页面、鼠标/触摸/键盘操作、实际播放会延长闲置有效期，每个会话最多每分钟持久记录一次续期。后台状态轮询不计为使用；主动开启的浏览器本地录制可在后台继续续期。Cookie 通过同源 API 按剩余有效期更新。

会话记录以 `0600` 权限原子保存在数据目录的 `sessions.json` 中，只保存随机令牌的 SHA-256 哈希，不保存可直接复用的 Cookie 值。有效登录在正常重启后保留；退出、改密码和管理员撤销后，受影响的会话在重启后也不会恢复。离线重置账号凭据也会使原账号的持久会话失效。从 v0.1.1 升级时需重新登录一次，因为旧会话只保存在内存中。

## 视频

默认 1080p30、4 Mbps、CPU libx264，先验证设备再选择 NVENC 或 4K。预设只是快捷填值，不能赋予设备不支持的能力；Linux 保存时会检查分辨率/帧率/格式组合。MJPEG 优先，YUYV 常受 USB 带宽限制。H.264 使用 baseline / 无 B 帧；关键帧间隔 1–5 秒。旋转 90°/270° 会交换实际显示宽高。

硬件控制项由设备报告，包括只读、inactive 和菜单约束；不支持的项不会编造出来。它们立即生效、不跟随配置文件导出，某些相机会在重启或自动曝光状态变化后复位。先保存选择的摄像头，再调整该设备的硬件控制。

## 音频

输入采样率应由设备支持。输出 Opus 固定 48 kHz；单/双声道和 16–256 kbps 可调。采集增益影响所有人，播放器音量只影响观看者。100 Hz 高通和频域降噪是可选项，不保证提升所有环境的音质。音画偏移正值延后声音、负值延后画面，应通过拍手等真实信号测量后调节。

## 常见问题

| 现象                 | 检查                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------- |
| 网页能开，媒体连不上 | 8189/UDP、8189/TCP；LANVORYN_MEDIA_HOST；Wi-Fi 客户端隔离和 VLAN；媒体进程是否在线      |
| 有画面没声音         | 点击开启声音；选择音视频而非仅视频；检查 audio.enabled、ALSA 设备、采样率和声道；看日志 |
| 摄像头 busy          | 停止 uStreamer、会议软件或其他占用程序；不要让两套采集同时运行                          |
| Permission denied    | 服务用户的 video/audio 组；设备节点权限；systemd 重启后生效                             |
| NVENC 失败           | 驱动、FFmpeg 编译支持、显卡可用性与编码会话资源；手动选择 CPU，不会静默回退             |
| 高延迟或卡顿         | 先降低分辨率、码率/帧率，检查 USB 带宽和 CPU/GPU；RTT 小不代表编码延迟小                |
| 登录后立即退出       | HTTP 下不要启用 Secure Cookie；检查反代 Host、PUBLIC_ORIGIN、服务器时间和会话期限       |
| 保存出现 409         | 其他页面已更新配置。重新加载后再编辑，避免覆盖别人的更改                                |
| 拒绝写请求           | 同源访问；反代保留 Host；原生 API 客户端带 X-Lanvoryn-Request: 1；不要开启任意跨域      |
| 定时停止后又手动开始 | 手动操作会转为手动模式；要恢复定时，重新选择计划策略并保存                              |

## 偏好设置

在登录页或控制台侧栏底部打开“偏好设置”，可选择语言，以及跟随系统、浅色或深色主题，选择保存在浏览器中。前端使用 i18next / react-i18next 和本地 JSON 资源，覆盖简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语。首次按浏览器偏好识别语言，`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO` 对应繁体中文。

设备名称、V4L2 控制标识、FFmpeg 原始错误和系统日志保持设备/服务器原文，便于检索技术故障。界面时间使用所选语言格式；定时窗口执行时区始终以服务器保存的计划时区为准，两者不要混淆。

## IP 属地

管理员在“访问安全”的会话列表中查看 IP 属地。公网地址由服务器通过 HTTPS 查询 [FreeIPAPI](https://freeipapi.com/)，无需账号或密钥；查询会向该服务发送被查询的公网 IP。局域网和保留地址在本地识别，不外发。国家名称随界面语言显示，省市名称使用数据源原文。属地是 IP 的大致位置，不代表设备实际位置。

`LANVORYN_IP_GEOLOCATION=true` 默认开启；设为 `false` 并重启应用可关闭公网查询。成功结果内存缓存 24 小时，失败缓存 1 分钟；每 10 秒最多 8 次请求，并合并同一 IP 的并发查询。官方免费档当前为每分钟 60 次、每 10 秒 10 次；超限、超时或不可用时显示状态，不影响登录和播放。只查询会话列表，事件日志继续记录原始 IP。

当前 `trustProxy=false`，使用实际连接来源；反向代理后可能显示代理 IP，不信任任意客户端转发头。

## 页面地址

`/login` 登录；`/live` 实时监看；`/settings` 采集参数；`/schedules` 定时计划；`/security` 访问安全；`/events` 运行日志。支持直接访问、刷新和浏览器前进后退，访客仅可进入实时监看。

## 按需采集

服务在线不代表持续采集。在允许观看的时段，每个播放器只请求所需输入：仅视频不请求麦克风，仅音频不请求摄像头。多个观看者的需求合并，因此其他观看者仍可能占用某个输入。暂停、离开播放页、切到后台或关闭网页后撤销该播放器的需求，主动开启的本地录制可在后台继续；最后一个观看者离开后停止采集。异常断网或浏览器未发出关闭请求时，需求在最后一次心跳后 30 秒到期，后台在约 2 秒内回收。

定时计划和持续开放控制可观看的时段，无人播放时仍释放设备。“隐私停止”会禁止观看并断开现有播放。浏览器默认静音仅控制本机输出；如只要画面，请选择“仅视频”。播放轨道组合变化可能短暂重连其他观看者。
